# Python Projects

A collection of Python projects built while learning through the "100 Days of Code: 
The Complete Python Pro Bootcamp" course. Each folder contains a standalone project.

## Featured Projects (OOP)

- **coffee-machine** – Coffee vending machine simulator using OOP (Menu, CoffeeMaker, 
  MoneyMachine classes)

## Other Projects

- **blackjack-game** – Console-based Blackjack game against the computer
- **caesar-cipher** – Text encryption/decryption using the Caesar cipher
- **calculator** – Simple calculator supporting basic arithmetic operations
- **hangman** – Classic word-guessing game with ASCII art
- **higher-or-lower-game** – Guess which item has higher stats
- **number-guessing-game** – Guess the number within a set range
- **password-generator** – Random secure password generator
- **rock-paper-scissors-game** – Classic Rock, Paper, Scissors
- **silent-auction** – Program to run a blind auction and determine the winner
- **treasure-island-game** – Text-based choose-your-own-adventure game

## Tech

Python 3, standard library only.

## About

Python fundamentals project collection covering functions, loops, and OOP — 
built while completing the "100 Days of Code: The Complete Python Pro Bootcamp" course.
